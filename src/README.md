# Alex Kameni - Portfolio

This is a modern, data-driven portfolio for Alex Kameni, a Machine Learning Engineer & AI Researcher. Built with Next.js, TypeScript, Tailwind CSS, and AOS.

## Features

- **Data-Driven**: All content is managed in `src/data/portfolio.ts`.
- **Modern Design**: Clean and professional UI using Tailwind CSS.
- **Animations**: Smooth scroll and entrance animations with AOS.
- **Responsive**: Fully responsive design for all devices.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Configuration

To update the content of the portfolio, edit the `src/data/portfolio.ts` file. The components will automatically update to reflect the changes.
